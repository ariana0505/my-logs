## En profundidad

### Sobre los enfoques

Anthropic no vende un solo producto, sino que aplica el mismo modelo base a distintos contextos de uso:

- **AI Agents**: agentes autónomos que ejecutan tareas de varios pasos, como el propio Claude Code.
- **Coding**: asistencia y automatización de desarrollo de software.
- **Atención a clientes**: agentes que responden consultas o resuelven tickets.
- **Educación, Finanzas, Salud, Seguridad**: verticales donde se adapta el uso del modelo a necesidades específicas de cada industria, por ejemplo análisis de datos financieros o soporte en investigación de seguridad.

### Sobre los productos

Se pueden agrupar en tres familias:

- **Para programar**: Claude Code (uso individual) y Claude Code Enterprise (para equipos y organizaciones, con controles adicionales de administración y seguridad).
- **Para colaboración y seguridad**: Claude Cowork (trabajo colaborativo con el agente) y Claude Security (enfocado en tareas de ciberseguridad).
- **Integraciones en herramientas existentes**: Claude para Chrome, Slack, Excel, PowerPoint y Word llevan las capacidades del modelo directamente a aplicaciones que ya se usan a diario, en vez de requerir cambiar de herramienta.

La idea general del video es mostrar que Claude Code —el foco de este curso— es solo una pieza dentro de un ecosistema más amplio de productos que comparten la misma tecnología base.
