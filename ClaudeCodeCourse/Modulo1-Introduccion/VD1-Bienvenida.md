# Objetivo del curso 🎯

Aprender a usar Claude Code de manera eficiente para aumentar nuestra productividad sin sacrificar calidad.

**Enfoque:** arquitectura, herramientas, contexto y flujo de desarrollo.

---

## Bloques del curso 📋

- /01 Introducción — Conceptos y proyecto
- /02 Claude Code en acción — Modelos, skills y MCPs
- /03 Spec-Driven Development — Workflow de desarrollo AI
- /04 Administración del contexto — Plugins, subagentes y tooling
- /05 Distribución de herramientas — Plugins y marketplaces
- /06 Guardrails y DX — Hooks, seguridad y tips

---

## En profundidad

El objetivo del curso no es solo aprender a «usar el chat» de Claude Code, sino dominar cuatro ejes que se repiten en todos los bloques:

- **Arquitectura**: cómo está construido Claude Code por dentro (agentic loop, modelos, tools, Agentic Harness), visto en detalle en el Módulo 1, VD4.
- **Herramientas**: qué acciones concretas puede ejecutar el agente sobre el sistema de archivos y el entorno.
- **Contexto**: cómo se le da información persistente al agente (`CLAUDE.md`, scope, skills, subagentes, commands, MCPs).
- **Flujo de desarrollo**: cómo se integra Claude Code al trabajo real de programar, desde Spec-Driven Development (Módulo 3) hasta guardrails y seguridad (Módulo 6).

Los seis bloques siguen una progresión lógica: primero entender los conceptos (01), después usarlos en la práctica con modelos y skills (02), luego estructurar el trabajo con un método formal como Spec-Driven Development (03), aprender a administrar el contexto a mayor escala con plugins y subagentes (04), distribuir esas herramientas a un equipo (05), y finalmente cuidar la seguridad y la experiencia de desarrollo con guardrails (06). Es decir: conceptos → práctica → método → escala → distribución → seguridad.
