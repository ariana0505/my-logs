## Instalación de Claude Code

Vamos a usar la instalación de Claude Code en la terminal usando el siguiente comando de acuerdo con la plataforma.

### macOS/Linux

```bash
curl -fsSL https://claude.ai
bash
```

### Windows (powershell)

```powershell
irm https://claude.ai
iex
```

### Windows (CMD)

```batch
curl -fsSL https://claude.ai -o install.cmd && install.cmd && del install.cmd
```
