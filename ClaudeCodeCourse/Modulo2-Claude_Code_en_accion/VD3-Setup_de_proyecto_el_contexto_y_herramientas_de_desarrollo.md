## Objetivos de la clase 🎯

## Context7

Es una plataforma que permite consultar documentación actualizada y específica de las versiones de software que usamos para construir.

Context7 fundamenta las respuestas del agente en documentación vigente y reduce el riesgo de utilizar APIs inexistentes u obsoletas.

---

## Monorepo

Use this folder to setup a monorepo, for albumcito-facilito project. Use latest version of turborepo to setup the monorepo, we will have a workspace for apps and other for apis. Use pnpm to manage versions.

Add to `CLAUDE.md` relevant information about workspaces

---

## Backend

Create an API for albumcito-facilito project using NestJS latest version and use TypeScript. Only create the setup with dependencies needed to run, test and lint. Add to root `CLAUDE.md` details about this project and create `CLAUDE.md` for the project with relevant information for development

---

## Frontend

Create a frontend Next.js application using version 16 with TypeScript and Tailwind. Just do the setup with dependencies needed to run, test and lint. Add to root `CLAUDE.md` details about this project and create `CLAUDE.md` for the project with relevant information for development.
